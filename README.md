# Python Modules — Tutorial Code

Hands-on Jupyter notebooks covering the **core Python data-science modules**: NumPy, Pandas, and Matplotlib. Each notebook walks through the essentials with runnable examples.

## Notebooks

| Notebook | Topic |
|---|---|
| `Numpy.ipynb` | Arrays, indexing, broadcasting, and vectorized operations |
| `Pandas.ipynb` | Series & DataFrames, selection, cleaning, grouping, and aggregation |
| `matplotlib.ipynb` | Line/bar/scatter plots, subplots, styling, and annotations |

## Getting started

```bash
pip install jupyter numpy pandas matplotlib
jupyter notebook
```

Open any notebook and run the cells top-to-bottom to follow along.
